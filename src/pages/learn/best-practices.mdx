# GraphQLベストプラクティス

GraphQL仕様は、ネットワークの処理、認可、ページネーションなど、APIが直面する重要な問題のいくつかについて意図的に沈黙しています。これは、GraphQLを使用する際にこれらの問題に対する解決策がないという意味ではなく、それらがGraphQLが_何であるか_の説明の範囲外であり、単に一般的な慣行であることを意味します。

このセクションの記事は絶対的なものとして受け取るべきではなく、場合によっては他のアプローチを優先して無視することも正当化されます。一部の記事では、Facebook内で開発されたGraphQLサービスの設計とデプロイに関する哲学の一部を紹介していますが、他の記事では、HTTP経由での提供や認可の実行など、一般的な問題を解決するためのより実践的な提案を提供しています。
