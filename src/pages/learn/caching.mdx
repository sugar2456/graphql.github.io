# キャッシング

<p className="learn-subtitle">オブジェクト識別子を提供して、クライアントがリッチなキャッシュを構築できるようにする</p>

エンドポイントベースのAPIでは、クライアントは[HTTPキャッシング](https://developer.mozilla.org/en-US/docs/Web/HTTP/Caching)を使用して、リソースの再取得を回避し、2つのリソースが同じであることを識別できます。これらのAPIのURLは、クライアントがキャッシュを構築するために活用できる_グローバルに一意の識別子_です。

GraphQLでは、特定のオブジェクトに対してこのグローバルに一意の識別子を提供するURLのようなプリミティブはありません。したがって、APIがそのような識別子を公開して、クライアントが特定の種類のキャッシングの前提条件として使用できるようにすることは、ベストプラクティスです。

## グローバルに一意のID

### スキーマでオブジェクトを識別する方法を標準化する

これの1つの可能なパターンは、`id`のようなフィールドをグローバルに一意の識別子として予約することです。このドキュメント全体で使用されているサンプルスキーマは、このアプローチを使用しています：

```graphql
# { "graphiql": true }
query {
  starship(id: "3003") {
    id
    name
  }
  droid(id: "2001") {
    id
    name
    friends {
      id
      name
    }
  }
}
```

これはクライアント開発者にとって強力なツールです。リソースベースのAPIのURLがグローバルに一意のキーを提供するのと同じように、このシステムの`id`フィールドはグローバルに一意のキーを提供します。

バックエンドが識別子にUUIDのようなものを使用している場合、このグローバルに一意のIDを公開することは非常に簡単かもしれません！バックエンドがすべてのオブジェクトに対して既にグローバルに一意のIDを持っていない場合、GraphQL層がそれを構築する必要があるかもしれません。多くの場合、型の名前をIDに追加して、それを識別子として使用するのと同じくらい簡単です。サーバーはその後、base64エンコードすることでそのIDを不透明にすることができます。

オプションとして、このIDは[グローバルオブジェクト識別](/learn/global-object-identification)を使用する際に`node`パターンで作業するために使用できます。

### 既存のAPIとの互換性

この目的で`id`フィールドを使用することに関する1つの懸念は、GraphQL APIを使用するクライアントが既存のAPIとどのように連携するかです。例えば、既存のAPIが型固有のIDを受け入れるが、GraphQL APIがグローバルに一意のIDを使用する場合、両方を同時に使用するのは難しい場合があります。

このような場合、GraphQL APIは以前のAPIのIDを別のフィールドで公開できます。これにより、両方の利点を得ることができます：

- GraphQLクライアントは、グローバルに一意のIDを取得するための一貫したメカニズムに依存し続けることができます。
- 以前のAPIと連携する必要があるクライアントは、オブジェクトから`previousApiId`を取得して、それを使用することもできます。

### 代替案

グローバルに一意のIDは過去に強力なパターンであることが証明されていますが、使用できる唯一のパターンではなく、すべての状況に適しているわけでもありません。クライアントが必要とする重要な機能は、キャッシングのためにグローバルに一意の識別子を導出する能力です。サーバーがそのIDを導出することでクライアントが簡素化されますが、クライアントも識別子を導出できます。これは、オブジェクトの型（`__typename`でクエリされる）といくつかの型固有の識別子を組み合わせるのと同じくらい簡単です。

さらに、既存のAPIをGraphQL APIに置き換える場合、GraphQLのすべてのフィールドが同じであるが、`id`だけがグローバルに一意に変更された場合、混乱を招く可能性があります。これが、`id`をグローバルに一意のフィールドとして使用しないことを選択するもう1つの理由です。

## まとめ

GraphQL APIでキャッシングを使用するためのこれらの推奨事項をまとめると：

- オブジェクト型に対してグローバルに一意のIDフィールドを定義することで、さまざまな種類のキャッシングを促進できます
